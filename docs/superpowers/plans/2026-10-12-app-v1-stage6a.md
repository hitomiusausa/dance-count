## Global Constraints

- **外部への送信・課金をしない**: Google Cloud TTS などの有料 API を呼ばない（dry-run と費用見積もりまで）。ネットワークに出るコードは `--yes` と `VOICES_ALLOW_PAID=1` の二重鍵の後ろだけ。テストはネット無しで通る。鍵・認証情報をリポジトリ・`public/`・ブラウザ側に置かない（ADC のみ）。
- `src/engine/` は無変更。`output/timing-audit-before.json`・ゴールデンは書き換えない（`timing:audit` を走らせたら `git checkout -- output`）。新しい音声バイナリは commit しない（Ruling 66）。
- `git add -A` / `git add .` 禁止（未追跡の `フィガー/`）。push しない。開発サーバーは自分用に 5199（5173 はひとみうさ用。触らない）。
- 関門: `npm test`（件数を報告）・`npm run -s typecheck`・`npm run -s build`（check-dist 込み。英パックだけで通ること・途中の ja パックを置くと落ちることを確かめる）。
