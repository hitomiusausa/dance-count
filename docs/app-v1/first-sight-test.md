# 初見テスト（G9）の台本 — 説明なしで ▶ まで

Ruling 105-2。目的: 初めて見る人が、説明なしでワルツのカウントを鳴らせるか。**成功の条件: 説明なしで ▶ まで 2 分以内**。

相手がいなければ「**公開後に**」やる（その場合もこの台本をそのまま使う）。

## 対象

1 名以上。**60〜70代・社交ダンスの経験者が望ましい**。このアプリを一度も見たことがない人。

## 用意

- ひとみうさの iPhone。**ホーム画面に追加したアプリではなく Safari**で、`http://<Mac の IP>:5199/?r=<時刻>` を開いた状態（追加したアプリは保存領域が別＝F34。https の置き場が決まっていればその URL の Safari でもよい）。
- 音量は聞こえる大きさに。マナーモードを切る。
- 記録係 1 名（ひとみうさ）。ストップウォッチ（iPhone の時計でよい）。
- 画面が見える位置で、**手出し・口出しはしない**。

## 手順

| # | 言うこと | 観察すること |
|---|---|---|
| 1 | 何も説明せず iPhone を渡し、「**ワルツのカウントを鳴らしてみてください**」 | 止まった所・押した物の順・言った言葉・かかった秒（▶ が鳴るまで） |
| 2 | 鳴ったら「**もう少しゆっくりにしてください**」 | 速さの 3 択に気づくか・かかった秒 |
| 3 | 「**止めて、タンゴにしてください**」 | 停止（■）→ 戻る → 種目選びの流れ・かかった秒 |

## 終わったら 3 つ聞く

1. どこで迷いましたか。
2. 読めなかった字・分からなかった言葉はありましたか。
3. もう一度使いたいと思いますか。

## 判定

- **成功**: 手順 1 が説明なしで 2 分以内に ▶ まで進んだ。
- **失敗した所**（2 分を超えた・別の画面に迷い込んだ・読めない字があった）は、統合レビューの Important と同じ扱い。直すかどうかは**ひとみうさが決める**（く！ちゃんは選択肢と根拠を出す）。
- 記録は `docs/app-v1/` に残す（相手の名前は書かない）。
