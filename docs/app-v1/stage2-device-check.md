# 段2 実機確認（ひとみうさの iPhone）

開き方: Mac で `npm run dev -- --host` → iPhone の Safari で `http://<Mac の IP>:5173/`（同じ Wi‑Fi）。
ホーム画面に追加しての確認は段7（PWA）で行う。

| # | やること | 期待 | 結果 |
|---|---|---|---|
| 1 | マナーモードのまま、ワルツ → ▶ | 声とカチカチ音が鳴る | |
| 2 | 音量を0にして ▶ | バナーは出ない（音量0は「鳴っている」扱い） | |
| 3 | マナーモードで鳴らない場合 | 2秒ほどで「音が出ていません」の枠。「音が出ない時は ›」で説明ページ | |
| 4 | 再生中に画面ロック → 戻る | 「再生が止まりました。もう一度 ▶ を押してください。」→ ▶ で最初から鳴る | |
| 5 | 再生中に電話がかかる（または Siri を呼ぶ） | 同上の1行が出る | |
| 6 | 1分ほど鳴らしたまま置く | 画面が暗くならない。暗くなった場合は「画面が暗くなることがあります」の案内が1回だけ出たか・音は続いたかを記録 | |

## だめだった時

- 1 や 3 で「マナーモードで鳴らない」が確実に起きる場合は、Ruling 6 の代償（無音の `<audio>` ループの併用）を Fable に上げて裁定をもらう。
- 8 で鳴らない（タップしても止まっている）場合は、前回カードの即再生（解除タップ→遷移→マウント後に再生開始）が iOS で拒まれている。結果欄にそう書いてく！ちゃんへ。
