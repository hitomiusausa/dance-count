# 段4 実機確認表（iPhone）— 声 S7・S8 の録音

> **正本は `device-check-master.md`。ここは記録。**

前提: Mac で `npm run dev -- --host --port 5199`（5173 はひとみうさの開発サーバーのまま）。iPhone の Safari で `http://<Mac の IP>:5199/?r=<時刻>`（同じ Wi‑Fi）。
**確かめる前に必ずページを再読み込み**（Safari が古いコードを持っていることがある。`?r=<時刻>` を付けると確実）。
録音は静かな部屋・iPhone 本体のマイクで。結果は「OK／気になる（何が）」で。
**段3 追加便の再確認（`stage3-device-check.md` の 17〜42）と同じ日に**見てもらう想定。

この表は 4 つに分かれています。

- **A 録音と再生（1〜18）**: 段4の完了条件の本体。シミュレーターでは OS のマイク許可ダイアログを押せず、録音の先（語の画面・完成の画面）に入れなかった＝**ここは実機でしか確かめられていない**。
- **B Safari の小さい画面（19〜24）**: iPhone SE の Safari は下のツールバーのぶん、見える高さが約 548（ホーム画面のアプリなら 667）。この高さの時だけ配置を詰めている（D33・Ruling 71）。
- **C 代理で決めたことを実物で見る（25〜31）**: ひとみうさが寝ている間に代理で決めた D23〜D25・D30〜D35。「このままでよい／変えたい」で。
- **F8 の記録**（表の最後）。

先に見られる画面（く！ちゃんが撮影・Chrome）: `~/.playwright-mcp/stage4-walk-<幅>-<状態>.png`（Task 9・75 枚）と `~/.playwright-mcp/stage4-t9b-<幅x高>-<状態>.png`（Task 9b・375×548 / 375×667 / 320×568）。

## F8 の記録（iOS の録音の形）

| 項目 | シミュレーター（iPhone SE 第3世代・iOS 26.3・Safari。Task 9） | 実機 |
|---|---|---|
| `MediaRecorder.isTypeSupported('audio/mp4')` | **true** | （3 で鳴れば記録は不要） |
| `isTypeSupported('audio/webm;codecs=opus')` | **true**（アプリはこちらで録る＝`MIME_TYPES` の先頭） | |
| webm/opus・mp4 で録って同じページで `decodeAudioData` | **どちらも読める**（Fable の実測。マイク無しの合成音） | 3 で確かめる（実際のマイクの音） |
| `navigator.audioSession.type`（何も設定しないページ） | `auto` | |
| `audioSession.type='playback'` のまま `getUserMedia` | `InvalidStateError`（だから録音の間だけ切り替える。`withRecordingSession`） | |
