# 段3 実機確認（ひとみうさの iPhone・Mac）

開き方: Mac で `npm run dev -- --host` → iPhone の Safari で `http://<Mac の IP>:5173/`（同じ Wi‑Fi）。Mac では `http://localhost:5173/`。
