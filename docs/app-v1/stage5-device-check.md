## C あわせて見てほしい文言（好み）

- 「あなたの名前」の欄に「山田先生」と打つと、生徒には「山田先生さんの声」と出る。
- 「配る」の語（「送る」の方が近いか）。
- 案内文の全文（生徒に届く文。ひとみうさの言葉に直してよい）。
- iOS の Safari では「…作れま／す。」のように「す。」だけの行や、句の途中の改行が出ることがある（Chrome は直した。Safari は CSS では直せない。気になる文があれば短くする）。
- S10「受け取りました」には上の「戻る」と下の「ホームへ」の 2 つの出口がある（このままにした）。
- 「ファイルから受け取る」は「先生の声で練習」→ S7 の中にあり、**ルーティンだけ受け取る生徒もここから入る**（入口の名前が「声」寄り。気になれば入口を考える）。
