# 曲の拍の取り方・初心者向け設定の修正

2026-10-23 13時台 / うさこ。直前の実装commit: `8005bf3`。ひちゃんの試聴: 「カウントが音楽の倍速では。4拍子を8拍子で捉えている感じ。ゆっくりの曲なのにカウントが速い」「くわしくの項目が素人には分かりづらい」。

## 原因と修正

前回は解析器の689個の候補をすべて1拍と解釈し、そのまま曲の拍地図へ入れていた。中央値の間隔は約0.459秒、約130.73回/分。発声のファイル内位置が正しくても、この拍の単位を誤ると速すぎるカウントになる。前回の718テスト・保存波形の照合は、曲の拍子・拍の単位や小節頭の正解を保証しない。

ひちゃんの試聴を受け、**この曲の試聴設定として、検出点を2つで1拍とする候補**へ変更。中央値約0.908秒、約66.08回/分。4拍子の設定は維持する。8拍子へ変更したり、一定BPMで置き換えたりしていない。音楽自体の速さは変えず、元の非一定時刻を1つおきに使うため、揺れや減速は保持する。

- 制作側の `tools/music-preview-track.ts` へ曲ごとの解釈を明記。元解析JSONは変更しない。全曲・全種目を自動で半分にする処理は追加しない。
- `revision: ...-atempo-v3-pulse2-phase0` に更新。原本hashだけで旧拍地図・decode済み区間を再利用しない。
- この原曲では3つの区間の開始・終了時刻を変えず、**以前の12小節候補を6小節候補へ読み替える**。音源の切り出し・音程加工・曲の速度は同じ。声・表示・曲先の待ち拍・声先・WAVは新しい同一拍地図から導く。
- 2小節の導入は、細かい旧8点ではなく新しい8拍（旧16点）を使う。初心者の準備時間も適切な長さへ変わる。

これは試聴に基づく修正候補であり、4拍子／小節頭／ルンバ適性の専門家監修済みを意味しない。位相は元候補の偶数点（phase0）で、別位相との聴き比べも受入に残す。

## 設定の言葉

音楽画面だけ、詳細の入口を「練習の設定」に変更。既存の他画面の「くわしく」は変えない。

| 以前 | 変更後 |
|---|---|
| 練習するところ・前半・12小節 | 曲のどこで練習しますか？・はじめ（約○秒） |
| 繰り返す回数・2回 | 同じところを何回くり返しますか？・2回続ける |
| 始める順番・曲が先 | 曲とカウント、どちらから始めますか？・曲を先に流す |
| あとから入るまで・2小節あと | 曲を何拍聞いてから数えますか？・8拍ぶん（2小節） |
| 声が先でも同じ待ちラベル | 何拍数えてから曲を流しますか？ |
| 数える声・オン／オフ | カウントの声・声も聞く／音楽だけ |
| 音声ファイルを作る | 保存する音声を作る。練習用の音声を保存する目的を見出しで示す |

選んだ数を使って「曲だけを8拍ぶん聞いたあと、声が入ります」と説明する。日英対応。設定群・通常画面の操作数は増やさない。小さな画面のnative select内で選択文字が切れないことも検査する。
