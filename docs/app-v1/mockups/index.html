同じ画面（ホーム・再生・録音）を3つの見た目で並べました。各ページの右上で「PC 幅の再生画面」に切り替えられます。

  • A Clear Blue今の青×白を大きく・太く。淡い青灰の地に白いカード。開く
  • B Studio Navy白地にネイビー、罫線で区切る。鳴っている拍だけ琥珀色。開く
  • C High-Contrast Friendly黒に近い文字と 2px の太い枠。文字は一段大きく、種目は1列。開く
