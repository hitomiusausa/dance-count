## 5. Open question（Fable へ・推奨の既定つき）

1. **起動の殻が描かれない（白が 1 秒を超える）**。ホーム画面のアプリの 2 回目以降で白 約 0.8〜2.8 秒・最初の起動で約 5〜7 秒。殻は 1 コマも写らず、Chrome の Slow 3G でも S1 の 0.1 秒前にしか描かれない。原因は `index.html` ではなく描画を止める 445 KB の CSS（`@font-face` 524 個）。— **推奨の既定**: 修正便で「殻が CSS を待たずに描かれる」形にする（`@font-face` を別の CSS に分けて描画を止めない読み方にする、が第一候補。文字は書体が来るまで端末の書体で出る）。その前に実機で白の秒数を測る（統合表の「最初の起動の白い時間」の行）。直すまでは今のまま（害は白の時間だけ）。
2. **S1 の 548 で「種目を選んでください」が先生カードの線にくっつく**（上の余白 0）。4px 空けると英語の 548・320 でタイル 9・10 が初期表示から 1〜4px はみ出す（ui:check で確認して戻した）。— **推奨の既定**: このまま（好み。ひとみうさが「詰まって見える」と言ったら、`.dc-home` の上の余白 4px を見出しに回す案を ui:check で確かめる）。
3. **S4 の小節の注意（閉じた行の 3 行目）が 320 の日本語で語の途中で折れる**（「ありま／せん。」）。注意の幅が約 200px しかなく、句で折る（`phrased`）と「。」が行頭に落ちて悪化した。— **推奨の既定**: このまま（320 だけ・めったに出ない）。直すなら注意を行の幅いっぱい（並べ替えのつまみの下まで）に広げてから句で折る（配置の変更なので別便）。
4. **マナーモードの文（ひとみうさへ・変更なし）**: S11 は「本体横のスイッチ（マナーモード）」、S2 の音が出ない枠は「本体の消音スイッチ」と、同じ物を 2 通りに呼んでいる。iPhone 15 Pro 以降はスイッチが無く（アクションボタン・コントロールセンターで切り替え）、その人には「スイッチ」が見つからない。— **推奨の既定**: v1 はこのまま。監修シートで呼び方を 1 つにそろえるか、「（またはコントロールセンター）」を足すかをひとみうさが決める。

6. **琥珀の現在カウントのグレースケール**は撮れていない（headless の Chrome で音の時計が進まない）。— **推奨の既定**: 統合表（Task 10）の段8の行に「再生中に画面をグレースケール（iPhone の設定 → アクセシビリティ → 画面表示とテキストサイズ → カラーフィルタ → グレイスケール）で、今のカウントが分かる」を 1 行足す。
