## 0 準備

- Mac で `npm run dev -- --host --port 5199`（5173 はひとみうさの開発サーバーのまま）。iPhone の Safari で `http://<Mac の IP>:5199/?r=<時刻>`（同じ Wi‑Fi）。
- **確かめる前に必ず再読み込み**（Safari が古いコードを持っている。`?r=<時刻>` を付けると確実）。
- **Safari と、ホーム画面に追加したアプリは保存領域が別（F34）**。Safari の確認（1 節）を**先に全部**やる。追加したアプリの中は空から始まる（正常）。
- **https の置き場が決まるまで 2 節は止める**（Service Worker は https でないと動かない＝F39。HANDOVER §0b の 1）。
- 録音は静かな部屋・本体のマイクで。LINE で送る相手は自分の Keep か家族。
