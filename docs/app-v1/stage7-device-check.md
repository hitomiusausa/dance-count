# 段7 実機確認表（ホーム画面のアプリ・オフライン・更新）

> **正本は `device-check-master.md`。ここは記録。**

前提: **https の置き場が要る**（`http://<Mac の IP>:5199` では Service Worker が動かない＝F39。localhost だけは例外で、iOS シミュレーターの Safari では SW が入ることを Task 12 で確かめた）。置き場はひとみうさが決める（Fable §3-1・HANDOVER §0b の「決めてほしいこと」）: (a) Cloudflare Pages の `*.pages.dev` に検証用として置く（おすすめ・D4 の「配信基盤は公開直前に許可」に当たるので許可が要る）(b) `cloudflared` の一時トンネル（確認の日だけ・URL は毎回変わる）(c) Mac で自己署名の証明書＋iPhone にプロファイル（勧めない）。**決まるまでこの表は止めておく**（どれもまだ何もしていない）。
確かめる前に必ず Safari で再読み込み（`?r=<時刻>`）。結果は「OK／気になる（何が）」で。段3 追加便・段4・段5の確認表と同じ日でよい。

**先に知っておくこと（iOS の決まり・F34）**: Safari とホーム画面のアプリは**保存領域が別**。Safari で録った声・受け取った声・ルーティンは、追加したアプリには入っていない（Simulator でも確認済み）。段4・段5の確認を Safari で済ませた後にこの表をやると、追加したアプリの中は空から始まる（正常）。

シミュレーターで済んでいる物（Task 12・`docs/app-v1/stage7-usability-walk.md` §3）: localhost の Safari で SW が入る・S12 の文だけで追加できる（SE・iOS 26.3）・追加の時点で start_url（`/`）が使われ S1 で開く・サーバーを止めて（機内モードの代わり）完全に閉じて開いてもワルツとパソドブレが進む・新しい版の帯 →「更新する」・追加したアプリで「ファイルを選ぶ」のピッカーが開く。**実機でしか見られないのは**: 機内モードそのもの・実際の音・マナーモード・WakeLock・大きい iPhone の共有シート・英語の iOS の語・Android・LINE・1 週間後・最初の起動の速さ。
