# 決定カード — 日本語の標準の声をどう作るか（段6b）

ひとみうさに決めてほしいこと（Ruling 69）。く！ちゃんはここで止まっています。**まだ何もお金はかかっていません**（音は 1 つも作っていません）。

## 背景

- 英語の声は Google の読み上げ（Google Cloud Text-to-Speech）で作りました。日本語も同じやり方が一番そろいます。
- ただ、Google Cloud の**無料お試し期間が終わりました**。続けるには「使った分だけ払う」設定（従量課金）に切り替える必要があります。

## えらぶ（どれか 1 つ）

| | やり方 | 費用 | 手間 | く！ちゃんのおすすめ |
|---|---|---|---|---|
| **A** | Google で作る（英語と同じ会社・同じ音質） | 毎月の無料枠の中ならほぼ 0 円。枠の外でも 1 回 1 円未満の見込み（**価格は未確認**。課金画面で確かめてください） | 下の手順 5〜10 分 | **おすすめ** |
| **B** | ひとみうさが自分で 12 語を録音する | 0 円 | 段4（録音の画面）ができてから。静かな部屋で 15 分ほど | A が駄目だった時の最後の手段 |
| C | VOICEVOX（無料のアニメ風の声） | 0 円 | 大きなアプリの導入・クレジット表記が要る | v1 では外す（声色が教室に合わない見込み） |

## A を選んだ時に、ひとみうさがやること（5〜10 分）

1. **Google Cloud コンソール**（ブラウザの Google Cloud の管理画面）→「お支払い」→ 請求先アカウントを**有料アカウントにアップグレード**（お試し終了の案内にある「アップグレード」ボタン）。
2. 同じ画面で **予算とアラート**（使いすぎた時にメールで知らせる設定）を作る: 月 **500 円**、50%・90%・100% でメール。
3. プロジェクト `project-cbd3f2d8-9635-49e4-83d` で **Cloud Text-to-Speech API** が「有効」になっているか確認（なっていなければ「有効にする」）。
4. Mac のターミナルで `gcloud auth application-default login` を実行 → ブラウザで Google にログイン。
   - 鍵（ログインの証明）は Mac の中（`~/.config/gcloud/`）に自動で置かれます。**アプリのフォルダには何も置きません。**
5. く！ちゃんに「**A で GO**」と言う → く！ちゃんが `npm run voices:plan` の表（何文字・いくらの見込み）を見せる → ひとみうさが「GO」→ 声の候補を作る → 聞き比べページ（`stage6-listening-check.md`）で聞いて「結果をコピー」→ 採用。

**やらないこと**: API キー（合言葉のような文字列）を作らない／鍵のファイルをダウンロードしない／鍵を LINE やメモに貼らない。

## B を選んだ時

段4の実機確認の日に、録音の画面で**日本語**を選んで 12 語（スロー・クイック・いち・に・さん・よん・ご・ろく・なな・はち・アンド・ア）を録る → ファイルにして AirDrop でく！ちゃんへ → 同じ聞き比べページで自分の声を判定。

## あわせて確認してほしいこと（代理で決めてあります。変えたければ一言で）

- **D26** 日本語の声の名前（ID）は `default-ja-female-v1` に固定（男性の声になっても変えない）。
- **D27** VOICEVOX（C）と Mac の読み上げ（`say`）は使わない。
- **D28** B の時も画面の表示は「標準の声（日本語）」のまま（生徒さんに誰の声かは出さない）。
- **D29** 読ませる文字は、いち・に・さん・よん・ご・ろく・なな・はち・スロー・クイック・アンド・ア（「し」「しち」は使わない）。
- 候補は最初「Neural2-B の 1 声 × 速さ 2 通り（24 語）」から聞くのでもよい（全部だと 6 候補 × 12 語）。
