# 段6 日本語標準音声 — 聞き比べの確認表

作成: 2026-10-12（段6a で雛形）／ 6b でひとみうさが埋める。正は `docs/app-v1/rulings.md` の Ruling 67・70。

## 開き方

1. Mac のターミナルで（く！ちゃんが用意します）:
   ```
   npm run voices:gate -- output/voices/<候補1> output/voices/<候補2> …
   python3 -m http.server 4175 --directory output/voices/gate/<日付>
   ```
2. iPhone の Safari で `http://<Mac の IP アドレス>:4175/` を開く（Mac と同じ Wi-Fi で）。
3. **イヤホンを外して、iPhone 本体のスピーカーで**聞く（生徒さんの環境）。二番目に AirPods でも。Mac のスピーカーは参考だけ。

## 聞く順

1. ことば 12 個（同じことばが 2 回鳴ります）→「自然／気になる／だめ」
2. カウントの流れ 10 本（ワルツ・タンゴ・チャチャ・サンバ・パソドブレ × 練習の速さと試合の速さ。カチッという拍の音つき）→「ずれない／ずれる」。「▶ 英語で聞く」で今の英語と聞き比べ
3. 候補ごとに「採用する／採用しない」

## 答え方

ページの一番下の「結果をコピー」→ く！ちゃんに貼り付けて送る。下の表 A〜C にそのまま貼る（答えは iPhone の中にだけ残り、どこにも送られません）。

## 判定の規則（Ruling 67-3・67-4）

- 採用できるのは **12 語とも「自然」**かつ **10 本とも「ずれない」**の声。
- 「気になる」が 1 語でもあれば、その語だけ作り直して（SSML・速さ）もう一度聞く。「だめ」が 3 語以上なら声を替える。
- 機械の確認（`gate-report.json`）: 声どうしの重なりが英語と同じ以下（試合の速さと、種目ごとの全パターン）。
  - 注: Ruling 67-4 の字面「練習の速さで重なり 0」は**今の英語の声でも満たせません**（サンバ `1a2` の「ア→2」が 16 分で、80 拍でも重なる＝既存の `timing:audit` と同じ）。`gate-report.json` には字面どおりの旗（`practiceRisksZero`）と英語比の旗（`practiceNotWorseThanEnglish`）を両方出しています。どちらで判定するかは Fable の裁定待ち。
- どの声も満たさなければ Ruling 5 の最終手段（ひとみうさの録音＝決定カードの B）へ。
